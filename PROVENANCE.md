# Provenance — which script produces which number in the manuscript

Every value below is regenerated by `./run_all.sh`. Section names follow the manuscript.

## Requirements

| | |
|---|---|
| Python | 3.9 or later |
| Packages | **numpy only.** No scipy, no RDKit, no Biopython, no pandas. |
| Docking (optional) | a `gnina` binary — v1.1 CPU build used here; it also provides smina's classical scoring functions, so all eight configurations come from one binary |
| Figures | PyMOL (open-source is sufficient); the `.pml` scripts use no plugins |
| Network | none. All inputs are in `inputs/`; ortholog and TSHR sequences are embedded in the scripts with their UniProt accessions and verified lengths. |

Runtime: ~3 minutes for everything except docking; ~35 minutes on 2 cores including docking.

## Suggested Data Availability text

> All analyses derive from two deposited structures (PDB 7FIH and 8I2G) and from UniProt
> entries listed in the ortholog table. Analysis code is plain Python requiring only numpy;
> RMSD between docked poses and the crystallographic pose is computed by graph isomorphism
> with enumeration of the ligand's automorphisms, because the docking software does not
> preserve input atom order. The complete package — scripts, raw docking output, transformed
> coordinates, alignments and PyMOL figure scripts — regenerates every reported value with a
> single command (`run_all.sh`) and is available at [repository].
